# NUEVA NOVELA — ESPACIO DE BÚSQUEDA

Este directorio pertenece a una **nueva novela independiente de WATH NEVER LEFT**.

WATH V1, WATH V2 y todo su canon permanecen intactos. El material de WATH puede conservarse y estudiarse como referencia, pero **no se incorpora automáticamente a esta nueva novela**.

## Estado actual

**Etapa: búsqueda de premisa.**

Todavía no existe:
- título definitivo;
- canon;
- protagonista definitivo;
- mundo definitivo;
- estructura definitiva;
- final definitivo.

El objetivo inmediato no es construir una gran mitología ni elegir una fórmula de estructura.

Es encontrar una **premisa sencilla, clara y fértil** que nos provoque ganas de descubrir qué ocurre y escribirla.

## Criterio central

La historia debe poder explicarse de forma sencilla.

El lector no debería necesitar conocimientos especializados para comprender el misterio principal.

La referencia conceptual es una premisa como **The Man from Earth**: una situación inicial extremadamente simple puede abrir preguntas enormes sin exigir que el lector sea especialista en ciencia, ingeniería o matemáticas.

Esto NO significa que la novela deba carecer de ciencia, misterio o profundidad. Significa que la **puerta de entrada** debe ser comprensible.

## Lo que buscamos

Una buena semilla debería tener:
- una situación fácil de imaginar;
- una anomalía o pregunta inmediata;
- consecuencias que generen investigación;
- potencial para recontextualizar lo anterior;
- una respuesta que pueda ser profunda sin exigir conocimiento técnico para seguir la historia;
- capacidad real de producir el impulso: **“quiero saber qué está pasando.”**

## Lo que evitaremos

No construir una novela alrededor de:
- una explicación científica que el lector tenga que estudiar para entender;
- una regla matemática cuya comprensión sea necesaria para disfrutar el misterio;
- una arquitectura gigantesca creada antes de encontrar la historia;
- una colección de rarezas sin consecuencia narrativa;
- un giro diseñado solamente para sorprender.

## Regla del laboratorio

Primero:

**SITUACIÓN → PREGUNTA → CURIOSIDAD → CONSECUENCIAS**

Después:

**INVESTIGACIÓN → RECONTEXTUALIZACIÓN → RESPUESTA**

Y solo cuando exista una historia sólida:

**ESTRUCTURA → PERSONAJES → CAPÍTULOS → MANUSCRITO**

No se adapta una idea a una estructura antes de saber qué historia quiere contar.

## Relación con los métodos de escritura

Los archivos de `METODOS_ESCRITURA/` se utilizan como **material de estudio**.

Sirven para analizar historias y descubrir herramientas.

No son instrucciones para imponer una fórmula a esta novela.

## Historial

Toda interacción de trabajo relevante debe conservarse en `HISTORIAL_CHAT/` con fecha y hora. Los registros históricos no son canon.

## Primera investigación descartada

La hipótesis del edificio con una discrepancia volumétrica de 30 m³ fue estudiada y posteriormente descartada como premisa geométrica literal. El experimento se conserva en:

`NUEVA_NOVELA/IDEAS_DESCARTADAS/ANOMALIA_30M3.md`

No se elimina porque el objetivo del laboratorio es conservar también lo que descubrimos al descartar ideas.

# PROMPT CLAUDE — ADAPTACION DEL PROLOGO A WNL

Este archivo contiene el prompt de trabajo para una segunda versión del prólogo, después de que Claude generara una primera interpretación libre del sueño real del autor. La primera versión no conocía el canon. Este prompt incorpora el canon vigente y las conclusiones extraídas de Claude, Gemini, Qwen y DeepSeek.

ESTADO: PROMPT DE TRABAJO / NO CANON.

[Prompt completo entregado al autor en el chat del 08/10/2026.]

Objetivo central:
Adaptar el prólogo libre inspirado en el sueño al canon de WATH NEVER LEFT, conservando intensidad emocional, misterio, prosa cinematográfica y el principio de "Él vive las realidades. El lector descubre qué significan."

Elementos destacados a preservar o transformar:
- culpa física por una tragedia accidental;
- responsabilidad por algo que no se quiso provocar;
- sensación de estar rodeado de personas que ven el problema pero no ayudan;
- terror corporal y certeza de muerte;
- persecución interminable;
- cuerpo que sabe luchar antes de que la mente sepa cómo;
- refugio afectivo inesperado con una persona amada;
- breve libertad/aventura durante una huida;
- escalada de amenaza;
- destrucción total seguida de silencio;
- banco y tren con pocas personas;
- cuatro marcas como inspiración no canónica, con reconocimiento sin comprensión;
- "Mario con las manos vacías" como imagen de abandono/impacto emocional.

Restricciones principales:
- Prólogo = Ventana 3 / 2014 / vida cotidiana.
- Primera persona estricta.
- Protagonista común y corriente.
- No fechas/años como apertura.
- No mencionar explícitamente la Habitación.
- No explicar las diez ventanas.
- No explicar el mecanismo de sueño.
- No explicar la naturaleza del protagonista.
- No explicar WATH.
- No convertir el sueño en una realidad objetiva ni en una undécima ventana.
- Prosa continua, natural, respirada y cinematográfica, no guion.
- Las pistas deben ser verdaderas, incompletas e interpretables.
- Las cuatro marcas no tienen significado definido.
- El tren no debe explicar nada.
- El cierre debe poder conducir naturalmente al sueño canónico sin revelar el sistema.

La versión completa del prompt fue preservada en el mensaje original de esta conversación y puede regenerarse desde allí si fuera necesario.

# GUÍA DE ETAPA — CORRECCIÓN Y EXPANSIÓN DEL MANUSCRITO

## Punto de partida

El manuscrito actual ronda las **20.404 palabras**. El objetivo de referencia de aproximadamente **3.500 palabras por capítulo** NO significa rellenar capítulos ni perseguir una cifra artificial.

La cifra sirve como referencia para permitirnos desarrollar mejor escenas que antes fueron comprimidas.

## Principio editorial central

**No agregar palabras: agregar historia.**

Cada expansión debe aportar al menos una de estas cosas:
- una escena que el lector pueda vivir;
- una conversación con contenido;
- una decisión del protagonista;
- una consecuencia;
- una relación o personaje mejor desarrollado;
- una experiencia dentro de la ventana;
- una respuesta parcial a una pregunta ya sembrada;
- una conexión entre hechos anteriores y posteriores;
- información que cambie el significado de algo que el lector ya vio.

Si una ampliación solo repite, explica lo mismo o crea frases para alcanzar un número, se elimina.

## Nueva estrategia narrativa

Hasta ahora hemos usado mucho el patrón:

**misterio → misterio → misterio → misterio**

A partir de esta etapa queremos equilibrarlo:

**misterio → descubrimiento → consecuencia → nueva pregunta**

No todos los misterios deben permanecer abiertos durante cientos de páginas. Algunos pueden recibir respuestas parciales o completas cuando la historia esté preparada para ello.

Resolver algo NO significa explicar todo. Una respuesta puede abrir una pregunta más profunda.

## Escala de WATH NEVER LEFT

No debemos pensar el proyecto solamente como una novela que necesita llegar a cierto número de páginas.

**Ready Player One tiene un mundo enorme.  
WATH NEVER LEFT tiene un universo enorme.**

Las diez ventanas no deben sentirse como simples escenarios de 24 horas. Cada una puede contener historia, personajes, conflictos, consecuencias, relaciones y descubrimientos propios.

La existencia de diez realidades nos da material suficiente para desarrollar una novela extensa sin necesidad de inflarla artificialmente.

## Corrección antes que expansión

Cuando retomemos el trabajo:

1. Primero corregir los errores detectados durante la segunda lectura.
2. Verificar continuidad temporal, objetos, personajes, transiciones y causas/consecuencias.
3. Después revisar qué partes necesitan desarrollo.
4. Solo entonces expandir capítulos donde exista historia real que contar.
5. Finalmente revisar ritmo para que la expansión no destruya la tensión.

## Expansión entre capítulos

Podemos adelantar elementos de capítulos posteriores o sembrar información que después tenga una respuesta, siempre respetando el canon.

Esto permite que acontecimientos anteriores adquieran nuevo significado sin convertir cada capítulo en una acumulación de pistas.

La pregunta editorial no será:

> “¿Qué misterio nuevo podemos agregar?”

Será:

> “¿Qué puede descubrir, comprender, vivir o sufrir el protagonista aquí que haga avanzar realmente la historia?”

## Regla de misterio

No convertir cada detalle en una pista.

El protagonista tampoco debe hacerlo. Ya existe una línea importante en el manuscrito: él empieza a comprender que una moneda puede ser simplemente una moneda y que no todo detalle cotidiano es una señal.

El lector debe poder distinguir entre:
- misterios importantes;
- detalles cotidianos;
- pistas reales;
- coincidencias;
- información que todavía no comprende.

## Prosa

Mantener la prosa narrativa continua.

No utilizar frases narrativas aisladas como golpes de tensión:
- “Esperé.”
- “No respondió.”
- “Seguimos caminando.”
- “Me quedé quieto.”

Las pausas, acciones y silencios deben integrarse dentro de párrafos completos siempre que sea posible.

El objetivo es una lectura cinematográfica, no un guion.

## Referencia de ritmo

**3.500 palabras por capítulo es una referencia, no una obligación.**

Un capítulo puede tener menos si la historia queda mejor así.

Un capítulo puede superar esa cifra si la escena necesita espacio.

La prioridad es:

**historia > ritmo > profundidad > extensión artificial.**

## Objetivo de esta nueva etapa

Hacer que WATH NEVER LEFT crezca porque **la historia lo necesita**, no porque necesitemos alcanzar un número de páginas.

Queremos que el lector no solo piense:

> “Quiero saber qué significa esto.”

También:

> “Quiero saber qué pasó después.”

Y, cuando llegue una respuesta:

> “Ahora entiendo aquello que vi antes.”

Ese equilibrio entre misterio, respuesta y consecuencia será una de las principales guías de la siguiente etapa editorial.

## Nota sobre Ready Player One

Ready Player One se utiliza como referencia de experiencia, escala y capacidad de construir un mundo atractivo, no como plantilla estructural.

La novela de WATH NEVER LEFT debe encontrar su propia longitud y estructura.

**WNL no necesita ser más larga para ser más grande.  
Necesita aprovechar el universo que ya tiene.**

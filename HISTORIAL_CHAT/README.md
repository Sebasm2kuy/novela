# HISTORIAL DEL CHAT — WATH NEVER LEFT

Esta carpeta es un archivo histórico separado del canon. Conserva, en orden cronológico, la evolución de las conversaciones y decisiones relacionadas con WATH NEVER LEFT / LO QUE NUNCA SE FUE.

**No es canon.** Lo que aparezca aquí describe lo hablado o decidido en los chats; no convierte automáticamente una idea histórica en una regla vigente.

## Orden
- Un archivo por día cuando existe información recuperable.
- Dentro de cada día, los acontecimientos aparecen ordenados por hora.
- Se conservan las horas disponibles con la precisión recuperada.
- Cuando solo existe un resumen y no el texto íntegro del chat, se indica como **resumen recuperado**.

## Importante
Este archivo se construye con el historial disponible para esta sesión y con registros recuperables de conversaciones anteriores. No existe acceso retroactivo garantizado al texto literal de absolutamente todos los mensajes ni a cada minuto. Por eso **no se rellenan huecos inventando contenido**.

## Separación
CANON/ = lo que actualmente rige la novela.
IDEAS/ = propuestas no confirmadas.
HISTORIAL_CHAT/ = lo que ocurrió en las conversaciones, incluso si después fue descartado.

El historial conserva decisiones antiguas porque su objetivo es preservar la evolución del proyecto.

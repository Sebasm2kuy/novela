# MÉTODOS DE ESCRITURA

Este directorio reúne métodos, estructuras y herramientas utilizadas para planificar, construir, analizar y revisar novelas.

## Archivo principal

- `CATALOGO_METODOS_Y_ESTRUCTURAS.md` — catálogo general y clasificación.

## Objetivo

Este material se incorpora al proyecto **WATH NEVER LEFT** exclusivamente como material de estudio.

No constituye canon, no modifica la historia y no obliga a utilizar ninguna estructura.

La intención es estudiar primero cómo diferentes escuelas y autores entienden la construcción de una historia y, posteriormente, decidir qué herramientas sirven —si alguna— para una novela concreta.

## Distinción fundamental

No todos los modelos son “fórmulas” en el mismo sentido:

- **Estructuras:** describen la forma de una historia.
- **Beat sheets:** dividen la historia en momentos funcionales.
- **Métodos de planificación:** explican cómo pasar de una idea a un manuscrito.
- **Modelos de personaje:** estudian transformación y psicología.
- **Sistemas de revisión:** sirven para diagnosticar una historia existente.
- **Modelos de género:** adaptan la estructura a expectativas específicas.

## Regla del proyecto

Primero se estudia la herramienta.

Después se crea la historia.

No se debe crear una historia simplemente para rellenar una plantilla.

## Referencias actuales

La documentación oficial de Save the Cat! describe actualmente su adaptación para novelistas mediante 15 beats, 10 tipos de historia, logline, transformación y herramientas de planificación.

Las comparativas contemporáneas de métodos de escritura consultadas también agrupan como marcos principales Three-Act, Hero's Journey, Save the Cat, Snowflake, Fichtean Curve, Seven-Point, Freytag, Story Circle y Kishōtenketsu.

La lista del catálogo es deliberadamente amplia, pero no pretende ser matemáticamente exhaustiva: existen innumerables variantes, métodos comerciales, sistemas de género y adaptaciones personales.

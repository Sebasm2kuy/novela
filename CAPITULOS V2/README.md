# WATH NEVER LEFT — CAPÍTULOS V2

Esta carpeta contiene la **nueva versión de trabajo del manuscrito**.

## Regla de versionado

- `CAPITULOS/` conserva la versión anterior y **no debe sobrescribirse** por trabajo nuevo.
- `CAPITULOS V2/` será la carpeta principal para los nuevos capítulos y revisiones de esta nueva etapa.
- Cuando un capítulo de V2 sea revisado, se modifica dentro de V2 sin alterar su equivalente histórico en V1.
- Las versiones anteriores deben permanecer disponibles para comparación, recuperación y auditoría de continuidad.
- El contenido de V2 no se considera automáticamente canon adicional: sigue estando sujeto a las reglas de `CANON/` y a la confirmación del autor.

## Inicio de V2

La V2 comienza con:

`00_PROLOGO.md`

Este archivo contiene la versión revisada del prólogo desarrollada en la nueva etapa narrativa.

## Objetivo

Mantener una separación limpia entre:
- la versión anterior del manuscrito;
- la nueva versión en desarrollo;
- el canon narrativo.

La separación permite comparar escenas y recuperar material anterior sin perder trabajo.
